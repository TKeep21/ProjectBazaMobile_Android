# Короткий текст для защиты

В приложении реализованы основные экраны домашних заданий: таск-менеджер и новости NY Times. Новости вынесены через `NewsRepository`, remote data source и cache data source, поэтому экран может показывать сохраненные данные при проблемах с сетью.

В качестве дополнительной фичи добавлен экран `Обзор`. Он использует задачи пользователя и показывает сводку: количество активных и завершенных задач, процент выполнения, флаги, просроченные задачи, задачи на ближайшие 24 часа, высокий приоритет и ближайший дедлайн.

Бизнес-логика обзора не лежит в Compose. Расчет вынесен в `TaskStatsCalculator`, а экран только отображает готовый результат. Это упрощает поддержку и позволяет тестировать core-логику без Android-инструментов.

Для проверки добавлены unit-тесты на `TaskStatsCalculator` и `TaskRepository`: проверяется пустое состояние, активные и завершенные задачи, дедлайны, приоритеты, добавление задачи, переключение статуса выполнения и сортировка по приоритету.

Архитектурное решение по экрану обзора описано в `docs/adr/0001-task-overview.md`. Проект собирается, тесты проходят.
