# ADR 0001: Экран обзора задач

## Контекст
Проект уже содержит базовые экраны домашек: таск-менеджер и новости NY Times. Для уверенной оценки 6-7 нужно показать дополнительную доработку функциональности и не держать бизнес-логику внутри Compose-экрана.

## Решение
Добавлен экран `Обзор` в нижнюю навигацию. Экран использует данные таск-менеджера и показывает:

1. общее количество задач;
2. активные и завершенные задачи;
3. процент выполнения;
4. задачи с флагом;
5. просроченные задачи;
6. задачи на ближайшие 24 часа;
7. активные задачи с высоким приоритетом;
8. ближайший дедлайн.

Расчет статистики вынесен в `TaskStatsCalculator`. Это обычный Kotlin-класс без зависимости от Android и Compose, поэтому его можно покрывать быстрыми unit-тестами.

## Последствия
1. Экран `Обзор` стал отдельной фичей внутри приложения.
2. UI отвечает только за отображение состояния.
3. Core-логика статистики проверяется unit-тестами.
4. Фича переиспользует текущий `TaskViewModel`, поэтому не дублирует источник данных.
